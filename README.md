# Kesari Manpower 

Employee Joining & Exit Formality Software (Phase 1) integrated with Frappe HRMS:
- 4 Excel Uploads (Employee, Salary, Bonus, Leave) + Photo ZIP with column mapping & validation preview
- Joining Kit (Offer Letter, Appointment Letter, Gratuity Form IV/F, Form 18 ID Card CR-80 & A4 sheet, EPFO Form 11) + Police Verification Letter
- Full & Final Settlement Engine (integer paise, Decimal ROUND_HALF_UP, formulas, 2-working-day deadline, maker-checker) + Service Certificate
- Minimum Wage & Increment Letters + Wage Watcher
- Encrypted PII (AES-256-GCM), Aadhaar masking, atomic reference numbers & append-only Audit Log
